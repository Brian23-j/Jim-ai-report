# report

用于跨 AI 平台复用经过用户审阅的上下文、Skills、偏好、项目规范和会话交接。

本仓库初始为空；完整目录与工具通过独立分支的 PR 交付，合并后请按完整 README 使用。

隐私边界：禁止提交 API Key、密码、私钥、访问令牌、原始聊天或个人敏感信息。长期记忆默认手动维护，或在明确同意具体更新后维护。私有仓库仍需人工审查。

仓库只管理文件版本，不会自动同步各 AI 的全部聊天记录、平台内置记忆、账号权限或运行环境。

## 小白安装人工智能环境

Windows 用户可进入 [`beginner-ai-environment/pi-web/`](beginner-ai-environment/pi-web/)，使用其中的脚本安装和管理 `pi-web`：

- [`install-pi-web.bat`](beginner-ai-environment/pi-web/install-pi-web.bat)：首次安装 Node.js、pi-web，并配置后台运行。
- [`pi.bat`](beginner-ai-environment/pi-web/pi.bat)：启动、停止、查看状态、打开网页、查看日志和更新。
- [`README.md`](beginner-ai-environment/pi-web/README.md)：面向小白的安装和使用说明。
