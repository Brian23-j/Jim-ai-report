# 长期偏好变更提案

- 操作：{新增 / 修改 / 删除}
- 目标：`context/preferences.json`
- 具体差异：{旧内容 -> 新内容}
- 适用范围：{哪些工作适用}
- 原因与不敏感来源：{用户确认摘要，不贴原始聊天}
- 确认状态：待确认；确认前不得写入长期偏好
- 确认日期：{确认后填写 ISO 日期}

条目结构示意（仅模板；不能直接作为已确认事实）：

```json
{
  "id": "preference-id",
  "statement": "{用户确认的偏好}",
  "scope": "{适用范围}",
  "confirmed_on": "{YYYY-MM-DD}",
  "source": "{明确同意的摘要}"
}
```
