# 模板

- [project.md](project.md)：稳定项目范围和规范。
- [status.md](status.md)：项目动态与证据。
- [handoff.md](handoff.md)：会话交接快照。
- [preference-change.md](preference-change.md)：需要明确确认的长期偏好变更。
- [start-session.md](start-session.md)：切换 AI 时粘贴的启动提示。
- [skill.md](skill.md)：新 Skill 骨架；填写完成后再放入 `skills/<名称>/SKILL.md`。

花括号字段为待填写内容，不是事实。无信息时填“未知”或“不适用”，不能猜测。
