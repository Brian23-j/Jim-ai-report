# 目录约定

| 内容 | 归属路径 |
| --- | --- |
| 环境安装脚本及配套说明 | `beginner-ai-environment/<工具>/` |
| 平台中立规则、已确认偏好 | `context/` |
| 自建工作流程 | `skills/<技能>/SKILL.md` |
| 第三方原始包和来源信息 | `library/` |
| 项目范围、规范与进度 | `projects/<项目代号>/` |
| 会话交接快照 | `handoffs/<项目代号>/` |
| 可复制模板 | `templates/` |
| 本仓库的校验与导出工具 | `scripts/` |
| 面向使用者的综合指南 | `docs/` |

目录名采用小写英文与连字符，说明文档使用 Markdown。每个安装工具目录包含 README，写明适用系统、安装顺序、日常操作和验证方法。

第三方包保留内部路径，方便追溯来源并核对 `library/manifest.json`。项目示例保留在 `example/`；真实项目使用独立代号。

GitHub PR 是分支之间的变更审阅记录。PR 来源分支的文件在该分支中可见；合并到默认分支后，仓库默认页面展示合并后的文件。目录树只描述当前检出的版本。
