# 隐私与安全规则

适用于 Markdown、JSON、YAML、脚本、提交说明、PR、导出包及附件。私有仓库并不消除泄露风险。

## 不得进入仓库的内容

- API Key、密码、私钥、访问令牌、会话 Cookie、认证头、带凭证的连接串，以及能用于恢复账户的资料。
- 身份证件、住址、电话号码、私人邮箱、财务、健康、精确位置、客户身份、真实用户数据等个人敏感信息。
- 原始聊天记录、数据库转储、包含敏感数据的日志、未审查的截图或完整平台配置。

需要记录关联时使用不敏感的代号和字段名，实际凭证留在密码管理器、系统钥匙串或运行时环境中。禁止为了让另一个 AI 访问而把凭证复制进仓库、提示词或 URL。

## 最小披露

- 不从当前对话、设备或平台记忆自动采集私人数据。用户授权保存长期记忆也不代表可以保存秘密或敏感信息。
- 只导出任务需要的项目、交接和 Skills；先审查包内容，再决定是否交给另一个平台。导出包与仓库有相同敏感边界，可能被上传的平台独立留存。
- 本地未审核草稿放 `.local/`，该目录不等于加密保险箱。不要将本地私人草稿移到其他未忽略路径以便提交。
- 提交前检查文件名、内容、暂存差异和提交说明。`.gitignore` 对已跟踪文件无效；基础检查可能漏掉秘密或个人信息，不承诺全量检测。

## 意外泄露

停止传播；对已泄露的凭证先撤销或轮换，再检查提交、分支、PR、历史及上传副本。只删当前文件不能清除历史。历史清理或改写须在明确授权、了解协作者影响后进行；本仓库工具不会自动执行这些操作。
